# Evidence: persona walkthrough videos

Each video was recorded by a Playwright end-to-end test in `e2e/evidence/` against a fresh production build (`scripts/e2e-server.sh`: clean D1, `vite build`, `vite preview`). The tests make real `expect()` assertions on the UI and the API, so a video exists only if every step in it passed. A yellow caption bar at the bottom of each video describes the current step. Phones are 390×844, staff desktops 1366×860, the kiosk is a 820×1180 tablet and the entrance board a 1280×720 TV. Playback is slowed down (`slowMo` 250 ms plus short pauses) so a person can follow it.

No `ANTHROPIC_API_KEY` was set, so the AI features ran on the app's built-in local engines: the deterministic menu assistant and onboarding parser, and the hawker-glossary translator. Emails go to the local outbox (`/m/inbox`) through the test `SEND_EMAIL` binding.

## Not shown, or shown only partly

- **Fairness bound** (host stand): the "fairness: skipped N× already" reason only appears after a party has been skipped several times, which the walkthrough doesn't stage. The setting ("Max times a party can be skipped") exists in Settings, and the seating API tests cover the bound.
- **Web Push on a real device**: headless Chromium has no push service, so video 01 subscribes the ticket to the app's dev push sink and asserts that a VAPID-signed push was delivered. The phone screen doesn't show a notification banner.
- **Claude / Workers AI engines**: with no API keys, the assistant, onboarding and translation run on the built-in engines (the videos say so). The Claude paths aren't exercised here.
- **Native browser prompts**: the POS uses `window.prompt`/`alert` for the drawer float, void reason, refund amount and drawer count. Headless screencasts don't render native dialogs, so the captions describe what was entered, and the test asserts the outcome.

## Re-recording

```sh
pnpm test:evidence                    # = EVIDENCE=1 playwright test --project=evidence (builds and starts the app on :5190)
FFMPEG=/usr/bin/ffmpeg ./scripts/evidence-videos.sh   # test-results/**/video-<name>/*.webm → docs/evidence/videos/<name>.mp4
```

Set `PW_CHROMIUM` to use a preinstalled Chromium. Recording needs Playwright's ffmpeg (`npx playwright install ffmpeg`). The `evidence` project runs only when `EVIDENCE` is set, so `pnpm test:e2e` doesn't include it.
